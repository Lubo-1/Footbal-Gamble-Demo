# FootbalGamble

Football Gamble je jednoduchá fotbalová sázková hra vytvořená v C# .NET. Hráč začíná s omezeným množstvím peněz a v každém kole si vybírá výsledek náhodně vygenerovaného zápasu mezi dvěma týmy nebo remízu. Na svůj tip vsadí částku, o kterou může podle výsledku buď přijít, nebo ji znásobit.
