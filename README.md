# Football Gamble

**Football Gamble** je jednoduchá fotbalová sázková hra vytvořená v **C# .NET**. Hráč začíná s omezeným množstvím peněz a v každém kole tipuje výsledek náhodně vygenerovaného zápasu mezi dvěma týmy nebo remízu. Vsadí částku, kterou může podle výsledku buď vyhrát, nebo ztratit.

> **Poznámka:** Kód může působit méně profesionálně, protože je vytvořen začínajícím vývojářem (junior), ale je plně funkční a dobře ilustruje herní logiku.
